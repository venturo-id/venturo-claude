## Dimensi bug

Skor dimensi ini = skor bug review Layer 1 (100 dikurangi penalti severity: {{SEVERITY_PENALTIES}} per temuan, dipatok minimal 0). Angka ini dihitung sistem dari hasil code review — model TIDAK menilai dan tidak perlu menyetor apa pun untuk dimensi ini. Tanpa skor bug yang diketahui (mis. review belum menghasilkan skor), dimensi ini dilewati (skipped) dan bobotnya dibagi ulang ke dimensi lain, bukan dianggap 0.
